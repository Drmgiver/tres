The desktop, reduced to three squares.

Tres is a lightweight, independent desktop environment for Linux. No permanent taskbar. No dock. Just the controls you need, and everything else out of your way.

Three white squares, centered at the edge of your desktop. Actual appearance depends on your settings.

One simple idea

All the essentials. Almost no chrome.

Each square has a job. Access programs, switch between open windows, or reach desktop controls without sacrificing screen space to a full panel.

Applications

The left square opens categorized application menus and application search for the software installed on your computer.

Running windows

The middle square lets you find and activate open windows without keeping a taskbar visible all day.

Controls & applets

The right square provides clock, audio, battery and other available desktop controls, session actions, and Tres configuration.

Designed to disappear

A real desktop session, not just a theme.

Tres runs as its own selectable Linux desktop session, with the lightweight Labwc Wayland compositor underneath. By default, normal windows can cover the three squares, keeping your workspace uncluttered.

Change the square size and colors, position, display scaling, keyboard shortcuts, and default applications through Tres settings. The familiar 19-pixel white squares remain the default.

Inspired by the classic LiteStep Tres theme, this is an original open-source recreation—not the original theme's source code.

  • Display system: Wayland
  • Compositor: Labwc
  • Desktop approach: three-square interface
  • Platform: Linux (apt-based installation documented)
  • License: GNU GPL v3
  • Status: evolving open-source project; hardware compatibility varies
Get started

Try Tres on Linux.

For apt-based distributions, follow the documented source installer. It sets up a separate Tres session at login, so you can keep your existing desktop available while testing.

Review the full installation and troubleshooting instructions first, especially if you have hybrid graphics. Experimental Debian packaging is also documented in the repository.

git clone https://github.com/Drmgiver/tres.git
cd tres
bash install.sh

Keep another working desktop installed while testing. Hardware and distribution support is still being expanded.

Good to know

About the project

Is Tres the same as Trinity Desktop Environment?

No. Tres Desktop Environment is an independent project and is unrelated to Trinity Desktop Environment (TDE).

How is Tres developed?

Tres uses human-directed, AI-assisted development. The project maintainer guides design, tests the result, and controls releases; AI assists with coding, debugging, and documentation.

Is Tres open source?

Yes. The source code is publicly available on GitHub under the GNU General Public License version 3.

Does Tres replace my existing desktop?

It installs as a separate selectable session. Keep your existing environment available, especially while testing hardware and driver compatibility.
